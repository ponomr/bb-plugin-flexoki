themes/flexoki.css maps the Flexoki base and accent values to BB roles, following the role table in the Flexoki documentation and the Visual Studio Code port. It keeps the 16 ANSI terminal colours, uses the font stacks from stephango.com/flexoki, and adds a compact text scale for BB.
